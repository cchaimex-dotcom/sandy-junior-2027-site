# Sandy & Junior 2027 — site editorial

Microsite responsivo criado a partir do relatório `Sandy_Junior_2027_newsletter_LOLA 2 (1).pdf`.

## Executar localmente

Na pasta deste projeto:

```powershell
python -m http.server 4173
```

Depois abra <http://127.0.0.1:4173>.

## Estrutura

- `index.html`: narrativa e conteúdo do relatório.
- `styles.css`: direção visual, responsividade e acessibilidade.
- `script.js`: revelação durante a rolagem, navegação e abas de evidência.
- `assets/`: imagens locais renderizadas do PDF usado como referência.
